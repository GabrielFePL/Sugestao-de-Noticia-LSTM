# Sugestao-de-Noticia-LSTM
Repositório para versionar o desenvolvimento de uma RNN aplicando o modelo LSTM para analisar o histórico de acessos de um usuário a um portal de notícias e prever seus próximos acessos. O insight para o desenvolvimento deste projeto provém do Projeto Transdisciplinar desenvolvido na faculdade Fatec Matão - Luiz Marchesan, o qual exige que os conceitos aprendidos em cada disciplina sejam aplicados em conjunto para entrega de um projeto semestral. O Projeto Transdisciplinar é realizado em grupos e com temas específicos prédefinidos para cada grupo, o meu grupo se baseiea no tema Portal de Notícias, justificando assim o presente projeto Sugestao-de-Noticia-LSTM.
